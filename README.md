# Youtube 要約マン v1.1

YouTubeの「この動画について質問する」機能を拡張し、**ワンクリックで詳細な要約指示（カスタムプロンプト）を送信・生成完了待機・Markdown保存までを全自動化**するChrome拡張機能（Manifest V3対応）です。

---

## ✨ 主な機能

1. **ワンクリックで詳細要約＆保存（全自動）**
   - 拡張機能のボタンを押すだけで、自動で質問パネルを開き、超詳細な要約プロンプトを送信。
   - Geminiが回答を書き終えるのを自動検知し、完了した瞬間にMarkdownファイルを自動ダウンロードします。
2. **動画を見なくても理解できる「超詳細プロンプト」**
   - デフォルトで、全体の概要・トピック別詳細（タイムスタンプ付き）・注意点・結論を網羅するプロンプトを搭載。
   - さらっとした短い要約ではなく、動画の内容が深く把握できる長文の解説を生成させます。
3. **プロンプトの自由なカスタマイズ（設定保存）**
   - ポップアップ内の「⚙️ 要約指示プロンプトの設定」から、いつでも自分好みの指示に変更・保存（Chromeストレージ）可能。
4. **表示中の要約をそのまま保存（即座保存モード）**
   - すでに画面上に表示されているAI回答を即座にMarkdown保存する手動ボタンも併載。
5. **文字化け完全防止＆Windowsファイル名対応**
   - UTF-8 BOM付き出力でWindowsのメモ帳でも文字化けゼロ。
   - ファイル名の禁止文字（`\ / : * ? " < > |`）や予約語を自動置換。

---

## 🚀 導入・更新手順

1. Chromeで `chrome://extensions` を開きます。
2. 「デベロッパー モード」をONにし、右下の **🔄（更新ボタン）** をクリックします。
3. YouTubeの動画ページを開いているタブで **`F5`（再読み込み）** を押します。

---

## 📖 使い方

1. 要約したいYouTube動画を開きます。
2. 拡張機能アイコンをクリックし、**「✨ ワンクリックで詳細要約＆保存」** を押します。
3. パネル起動 → プロンプト送信 → 生成待機（経過秒数が表示されます）が自動進行します。
4. 生成が完了すると、自動的に `【動画タイトル】.md` がダウンロードされます！
